# netbsd-games

## Play

With [av](https://asciiverse.sh), the Asciiverse client:

Each game installs on its own:

| Game | With av | From a release archive |
|---|---|---|
| BSD Backgammon | `av install bsd-backgammon` | `./backgammon` |
| Canfield | `av install canfield` | `./canfield` |
| Cgram | `av install cgram` | `./cgram` |
| Hack | `av install hack` | `./hack` |
| Hunt | `av install hunt` | `./hunt` |
| Larn | `av install larn` | `./larn` |
| Phantasia | `av install phantasia` | `./phantasia` |
| Rain | `av install rain` | `./rain` |
| Rogue | `av install rogue` | `./rogue` |
| Warp | `av install warp` | `./warp` |
| Worms | `av install worms` | `./worms` |

Start one with `av play <name>`.
